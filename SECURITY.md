# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability in BookLab, please report it responsibly instead of opening a public issue.

**Preferred:** Use [GitHub private vulnerability reporting](https://github.com/SpencerCornish/booklab/security/advisories/new) for this repository (Security → Report a vulnerability)

## Scope

Reports should cover this repository’s code (Go server, embedded web app, Docker/Make tooling). Third-party services (Stripe, your mail provider, hosting) have their own security programs.

## Supported versions

Security fixes are applied to the default branch (`master`). Self-hosted operators should pull the latest release or commit after a fix is published.
